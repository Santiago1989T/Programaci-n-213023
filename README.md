# 🛠️ Sistema de Gestión POO - Software FJ
# Aplicación de consola en Python diseñada para la gestión integral de clientes, servicios y reservas. El sistema destaca por una arquitectura profesional basada en Programación Orientada a Objetos y una alta tolerancia a fallos.

# 📌Puntos Clave:
# Diseño de Clases: Uso de Abstracción y Herencia para gestionar diversos servicios (Salas, Equipos, Asesorías) con cálculos de costo polimórficos.

# Seguridad de Datos: Encapsulamiento estricto de información del cliente y validaciones de entrada en tiempo real.

# Resiliencia: Manejo avanzado de excepciones personalizadas y bloques try-except-finally para evitar cierres inesperados.

# Auditoría: Registro automático de errores y eventos en un archivo de log externo.

# Modularidad: Código extensible que permite añadir nuevos tipos de servicios o reglas de negocio sin afectar la estructura base.
